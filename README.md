O aplicativo Android desenvolvido em Kotlin neste TCC que implementa a metodologia SayMore para anotação linguística de áudio e vídeo. Criado especificamente para pesquisadores e documentalistas linguísticos, o aplicativo oferece um ambiente móvel para a adição de marcadores temporais com transcrições e traduções, permitindo a associação de falantes a segmentos específicos de fala e exportação dos dados em formatos padronizados (CSV, XML e ELAN). Com uma abordagem inspirada na metodologia SayMore, o aplicativo facilita o trabalho de documentação em campo, possibilitando a criação de corpora linguísticos estruturados diretamente em dispositivos móveis e estabelecendo um fluxo de trabalho eficiente entre a coleta inicial de dados e a análise posterior em ferramentas especializadas de desktop.
